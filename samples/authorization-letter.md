# Authorization to test — Northwind practice lab (sample)

This is a sample authorization letter for local development. The seeded demo
engagement "Northwind practice lab" points at it.

- **System under test:** the Ares practice target (`cmd/ares-practice`), running
  on this machine at `http://127.0.0.1:8089` only.
- **Scope:** `127.0.0.1`. Nothing else.
- **Approved by:** Northwind Admin (the developer running it).
- **Window:** any time while the practice target is running.

The practice target is deliberately weak and every weakness is simulated. A real
engagement needs a real, signed letter from someone who owns the system.
